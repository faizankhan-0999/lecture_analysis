# Theme and visibility update

Only UI styling was adjusted in this update. The app logic, Gemini configuration, PDF processing, chunking, generation prompts, and study features were not changed.

Changes: stronger contrast for normal/hover/focus button states; visible uploader and download button labels; clearer body text, headings, inputs, tabs, alerts, and metric cards; matching dark theme settings.

After uploading the changed files to GitHub, Streamlit Cloud should redeploy automatically. If it does not, open Manage app and restart the app.

Note: CSS selectors for Streamlit widgets can vary between Streamlit versions. Verify the uploader, download buttons, and other controls in the deployed app after redeployment.
